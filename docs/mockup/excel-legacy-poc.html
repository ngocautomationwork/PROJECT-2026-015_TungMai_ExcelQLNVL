2. Mở file WORKING

Đúng file Simulation cũ. Không MASTER, không GiaoKhach, không dashboard MRP.

  • Giữ 5 dòng: SALE / BALANCE / Produce / Delivery / STOCK
  • Giữ CODE, CODE2…CODE6
  • Giữ tab Packing, ASSY, AI, SMD

3. Refresh All

Power Query đọc file mới nhất trong mỗi folder, ghi history, chống trùng.

  • Sales → thứ Năm trong bucket
  • KHSX → đúng ngày công đoạn
  • Tồn → snapshot theo kỳ
  • Refresh 2 lần: không duplicate

4. Xem kết quả

Một sheet thấy: mã NVL, code cũ/mới, thành phẩm, BOM, Sales, KHSX, NCC, tồn, thừa thiếu theo ngày.
